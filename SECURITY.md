# Security

Do not commit credentials, production personal data, or secrets. All `VITE_*` variables are public browser code; never place secrets there.

Report vulnerabilities through GitHub's private vulnerability reporting when enabled on this repository. If unavailable, contact a repository maintainer through an existing private channel; do not post exploitation details in a public issue.

Dependabot checks npm and Actions every Monday at 09:00 America/New_York. CI fails on high/critical dependency advisories. Review upgrades and lockfile changes; do not bypass the audit with an unconditional success.
